# EFA-017 — Introduce reusable football tag groups and terminology

**Status:** in_progress
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** catalog
**GitHub issue:** [#17](https://github.com/mfreeze77/exais-football-ai/issues/17)

## Outcome and user value

Apply consistent labels across games while allowing the owner to use their own football vocabulary.

## Scope

- Add editable groups for phase, skill, formation, play concept, result, and review purpose with optional presets.
- Support tag aliases/renames with explicit migration of existing associations and counts.

## Non-goals

- Automatic tactical interpretation, a mandatory universal playbook, or changing accepted human labels without review.

## Acceptance checks

- [ ] A preset can apply a small useful tag set without requiring every metadata field.
- [ ] An alias resolves to one canonical tag and avoids duplicate search results.
- [ ] A rename previews affected clips and updates associations atomically.
- [ ] Deleting a preset does not erase tags already applied to film.
- [ ] Imported unfamiliar tags remain recoverable and can be mapped by the owner.

# EFA-006 — Add durable timed coaching notes

**Status:** in_progress
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** review
**GitHub issue:** [#6](https://github.com/mfreeze77/exais-football-ai/issues/6)

## Outcome and user value

Record what to watch and reopen the relevant moment without relying on filenames.

## Scope

- Create/list/delete clip notes with optional source-relative timestamps.
- Display note markers or links that seek the selected source to the stored moment.

## Non-goals

- Audio dictation, collaborative comments, or editable Kinovea drawing objects.

## Acceptance checks

- [ ] An untimed note and a timed note survive restart and return against the correct clip.
- [ ] A timed note accepts zero and source-duration boundaries according to the API contract, and rejects out-of-bounds/non-finite values.
- [ ] Deleting a note from one clip cannot delete a note belonging to another clip.
- [ ] A note containing HTML is displayed as text and cannot execute code.
- [ ] Clicking a timed note seeks to that source-relative moment without rewriting trim bounds.

## Risks and evidence boundaries

- Notes outside the selected interval still belong to the original source; the UI must make that context clear.
- Deleting a note must never delete film.

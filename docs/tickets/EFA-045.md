# EFA-045 — Show storage health and safely reclaim derived caches

**Status:** planned
**Milestone:** M4 — Desktop convenience, recovery, scale, and release confidence
**Priority:** P1
**Area:** storage
**GitHub issue:** [#45](https://github.com/mfreeze77/exais-football-ai/issues/45)

## Outcome and user value

Understand disk use and remove reproducible previews/exports without risking original game film.

## Scope

- Report storage use by originals, thumbnails, exports, analysis artifacts, temporary files, and backups.
- Offer a concrete selection/preview for deleting regenerable caches and completed export copies, with reference checks.

## Non-goals

- Original-source deletion, removing the only copy of a reviewed sidecar, or assuming archive means safe to erase.

## Acceptance checks

- [ ] Storage totals identify the managed paths and artifact types being counted.
- [ ] Cleanup preview states which files will be removed and whether each can be regenerated.
- [ ] Running jobs, active downloads, and required provenance artifacts are excluded or safely coordinated.
- [ ] Cleanup rejects paths outside the managed workspace and refuses original media.
- [ ] Deleting a thumbnail/export leaves clip metadata, source film, review history, and playlists usable.
- [ ] Failed deletions report remaining files rather than claiming all space was recovered.

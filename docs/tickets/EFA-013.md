# EFA-013 — Import and review football-cv position suggestions safely

**Status:** implemented
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** integrations
**GitHub issue:** [#13](https://github.com/mfreeze77/exais-football-ai/issues/13)

## Outcome and user value

Attach external analysis to the right clip while keeping model suggestions distinct from coaching labels.

## Scope

- Accept a revision-pinned position bundle with source SHA-256 and per-play tracking IDs.
- Store immutable suggestion payloads and explicit unreviewed/accepted/rejected human review status.

## Non-goals

- Running a detector, calibration UI, named-player recognition, or deriving play/technique tags from positions.

## Acceptance checks

- [x] A valid position bundle is stored as unreviewed and lists its upstream revision.
- [x] A mismatched source SHA-256 is rejected without retaining a misleading analysis record.
- [x] Unsupported position tokens, malformed IDs, unknown schema fields, and non-finite data are rejected.
- [x] Changing review status preserves the imported payload and cannot affect another clip's record.
- [x] Accepting a suggestion does not assign roster players or populate human tags.
- [x] The UI identifies this as external analysis import and does not imply model execution is installed.

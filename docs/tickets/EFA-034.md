# EFA-034 — Render reviewed position overlays with source audio and timing

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** media
**GitHub issue:** [#34](https://github.com/mfreeze77/exais-football-ai/issues/34)

## Outcome and user value

Watch useful player-position boxes while retaining the sound and provenance of the original play.

## Scope

- Render optional overlays from validated tracking artifacts and accepted correction layers.
- Preserve source audio according to a documented mapping policy and keep original/overlay playback separately available.

## Non-goals

- Replacing source footage, silently baking unreviewed names into video, or copying the upstream renderer unchanged.

## Acceptance checks

- [ ] A generated motion fixture verifies box placement, label timing, output duration, and preserved audio.
- [ ] Rendered files cite source hash, run ID, reviewed label revision, and render settings.
- [ ] The owner can switch between clean film and the derived overlay without losing the playback moment.
- [ ] Failed renders leave no completed artifact and can be rerun from preserved intermediates.
- [ ] Unknown/low-quality tracks can be hidden without deleting the raw analysis.
- [ ] Different source frame rates and proxy transforms are qualified before being declared supported.

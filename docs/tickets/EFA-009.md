# EFA-009 — Favorite and archive clips without losing film

**Status:** in_progress
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** catalog
**GitHub issue:** [#9](https://github.com/mfreeze77/exais-football-ai/issues/9)

## Outcome and user value

Keep the active library focused while retaining earlier clips for later retrieval.

## Scope

- Save favorite and archived flags through versioned metadata edits.
- Expose quick favorite filters and an explicit archive view.

## Non-goals

- Source deletion, disk cleanup, or inferring a coach's approval from a favorite.

## Acceptance checks

- [ ] Favoriting a clip updates the favorites filter and summary count.
- [ ] Archiving removes the clip from the default active library but leaves its source and history intact.
- [ ] Unarchiving restores the same clip ID and relationships.
- [ ] Archived clips remain addressable and their playlist presentation is documented.
- [ ] A stale favorite/archive update triggers the normal concurrency conflict rather than overwriting newer edits.

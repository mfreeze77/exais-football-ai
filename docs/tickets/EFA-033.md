# EFA-033 — Import full analysis artifacts with a versioned manifest

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** analysis
**GitHub issue:** [#33](https://github.com/mfreeze77/exais-football-ai/issues/33)

## Outcome and user value

Inspect how positions were produced and rebuild overlays without losing intermediate evidence.

## Scope

- Extend the position-only adapter with schemas for detections, tracks, teams, field coordinates, snap, and labels.
- Ingest a manifest with hashes, timebase, transform chain, and links to each immutable per-run artifact.

## Non-goals

- Accepting arbitrary pickle/model objects, trusting archive paths, or treating partial output as complete analysis.

## Acceptance checks

- [ ] Fixture bundles from the pinned revision validate against explicit adapter schema versions.
- [ ] Every referenced file exists, matches its recorded checksum, and remains inside its managed run directory.
- [ ] Frame indices/timestamps and box coordinates are checked against the declared source/proxy transform.
- [ ] Missing, malformed, oversized, or wrong-source artifacts block final acceptance with precise diagnostics.
- [ ] Position-only imports remain compatible and clearly lack richer track/render capability.

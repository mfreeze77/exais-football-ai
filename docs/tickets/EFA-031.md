# EFA-031 — Review analysis suitability and pre-snap context

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** analysis
**GitHub issue:** [#31](https://github.com/mfreeze77/exais-football-ai/issues/31)

## Outcome and user value

Avoid spending analysis time on clips that cannot support reliable alignment-based positions.

## Scope

- Add a preflight checklist backed by actual clip properties and owner-selected snap/context timestamps.
- Record offense direction, team-color/role review, camera cuts, crop context, and reasons for unsuitable clips.

## Non-goals

- Automatic play recognition, assuming the ball is visible, or presenting a model snap estimate as ground truth.

## Acceptance checks

- [ ] A clip with missing calibration or insufficient pre-snap context is marked needs_input with a clear next action.
- [ ] Manual snap selection uses the source timestamp/frame mapping and is persisted in the run request.
- [ ] Team/direction assignments are explicit reviewed inputs or labeled suggestions.
- [ ] A detected or manually marked camera cut prevents treating incompatible calibration as continuous.
- [ ] The owner can still catalog/watch an unsuitable clip with analysis disabled.

## Risks and evidence boundaries

- Very short highlights may omit the alignment that drives position classification.
- Camera movement and jersey-color similarity can degrade geometry and team assignment.

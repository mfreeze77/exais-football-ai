# EFA-024 — Save searches and maintain dynamic clip collections

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** playlists
**GitHub issue:** [#24](https://github.com/mfreeze77/exais-football-ai/issues/24)

## Outcome and user value

Reopen a category such as tackling clips needing another look without rebuilding filters each time.

## Scope

- Persist validated filter specifications as named saved searches.
- Expose dynamic result counts/order and optional conversion to a fixed playlist snapshot.

## Non-goals

- LLM-generated query execution, arbitrary SQL, or silently changing fixed playlist membership.

## Acceptance checks

- [ ] A saved search reuses the documented filter semantics after restart.
- [ ] Newly labeled clips enter dynamic results while fixed playlists stay unchanged.
- [ ] Unsupported filter versions are reported rather than ignored.
- [ ] Converting results to a playlist preserves the reviewed order and selected clip IDs.
- [ ] Renaming a tag through the taxonomy workflow has a documented effect on saved searches.

# EFA-029 — Qualify a pinned external football-cv environment

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** integrations
**GitHub issue:** [#29](https://github.com/mfreeze77/exais-football-ai/issues/29)

## Outcome and user value

Make optional analysis reproducible without adding heavy models to every film-room installation.

## Scope

- Define an isolated external environment pinned to the reviewed football-cv revision and explicit dependency/model versions.
- Record actual detector backend, device, weights provenance, licenses, cache location, and diagnostic health output.

## Non-goals

- Bundling an unreviewed model, silently downloading weights at app startup, or claiming the README detector description matches code.

## Acceptance checks

- [ ] A declared environment records the football-cv commit and installed dependency versions.
- [ ] Preflight reports the actual RF-DETR or torchvision backend and selected device, including unavailable reasons.
- [ ] The stale ultralytics dependency guard is investigated with a documented upstream-compatible fix or an explicit requirement.
- [ ] Any model acquisition is a separate deliberate setup operation with source/license/checksum recorded.
- [ ] The base film library starts and remains usable with the entire CV environment absent.

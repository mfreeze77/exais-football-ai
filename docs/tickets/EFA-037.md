# EFA-037 — Evaluate position quality on representative owner film

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** quality
**GitHub issue:** [#37](https://github.com/mfreeze77/exais-football-ai/issues/37)

## Outcome and user value

Know which analysis suggestions are useful for this footage and where the owner must review closely.

## Scope

- Create an authorized local evaluation set with varied games, views, lighting, and positions, plus human labels.
- Measure per-class confusion, coverage, track quality, calibration error where available, runtime, and failure reasons.

## Non-goals

- Committing private game footage, transferring benchmark percentages from another dataset, or declaring success from a single attractive overlay.

## Acceptance checks

- [ ] Evaluation records source hashes and annotation policy while keeping actual private film outside git.
- [ ] Train/tune/evaluate splits keep plays and related frames separated to prevent leakage.
- [ ] Results include class counts, unknown/unlabeled cases, and errors as well as aggregate metrics.
- [ ] The report compares unreviewed suggestions to reviewed labels and states uncertainty/sample limitations.
- [ ] Only supported footage profiles are enabled as qualified; unsupported cases remain review-first.
- [ ] A reproducible command and environment manifest permit rerunning the evaluation.

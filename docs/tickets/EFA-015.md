# EFA-015 — Qualify source safety and the complete local media workflow

**Status:** in_progress
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** quality
**GitHub issue:** [#15](https://github.com/mfreeze77/exais-football-ai/issues/15)

## Outcome and user value

Establish evidence that core editing and export preserve the owner's film and reject unsafe requests.

## Scope

- Run meaningful API/storage/security tests and one generated real-FFmpeg import-to-export workflow.
- Check duplicate imports, concurrency, relationships, timestamps, range playback, safe paths, XML, and wrong-source analysis.

## Non-goals

- Real model accuracy claims, live Windows Kinovea checks, or unsupported CI results reported as executed.

## Acceptance checks

- [ ] Generated test video with an audio tone proves import, persistence, selected export duration, audio retention, and unchanged source hash.
- [ ] Negative tests exercise traversal/unsafe filenames, invalid relationships, stale edits, unsafe KVA, and wrong-source AI results.
- [ ] Failure tests assert the actual returned error fields and durable job state.
- [ ] The recorded qualification report distinguishes executed checks, failures, and environment-blocked gates.
- [ ] No real game footage, model weights, credentials, or runtime database enters the commit.

**Status:** implemented

**Area:** quality

## Outcome and user value

Establish evidence that core editing and export preserve the owner's film and reject unsafe requests.

## Scope

- Run meaningful API/storage/security tests and one generated real-FFmpeg import-to-export workflow.
- Check duplicate imports, concurrency, relationships, timestamps, range playback, safe paths, XML, and wrong-source analysis.

## Non-goals

- Real model accuracy claims, live Windows Kinovea checks, or unsupported CI results reported as executed.

## Acceptance checks

- [x] Generated test video with an audio tone proves import, persistence, selected export duration, audio retention, and unchanged source hash.
- [x] Negative tests exercise traversal/unsafe filenames, invalid relationships, stale edits, unsafe KVA, and wrong-source AI results.
- [x] Failure tests assert the actual returned error fields and durable job state.
- [x] The recorded qualification report distinguishes executed checks, failures, and environment-blocked gates.
- [x] No real game footage, model weights, credentials, or runtime database enters the commit.

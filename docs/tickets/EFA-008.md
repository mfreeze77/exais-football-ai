# EFA-008 — Manage games and a simple manually maintained roster

**Status:** implemented
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** catalog
**GitHub issue:** [#8](https://github.com/mfreeze77/exais-football-ai/issues/8)

## Outcome and user value

Associate clips with the game and people the owner knows.

## Scope

- Create and list games with opponent/date/season/notes.
- Create and list player records with name, jersey, and position; associate clip metadata with these IDs.

## Non-goals

- Automatic roster import, jersey OCR, face recognition, or treating per-play track IDs as roster IDs.

## Acceptance checks

- [x] Game creation requires title and opponent and preserves optional fields.
- [x] Player creation preserves names, jerseys, and positions without treating jerseys as globally unique identities.
- [x] A clip can reference multiple existing players and an optional existing game.
- [x] Invalid relationship IDs cannot be saved.
- [x] The UI creates a game/player and then makes it available for clip assignment without restarting.

# EFA-019 — Support alternative cuts and multiple views of one source

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** media
**GitHub issue:** [#19](https://github.com/mfreeze77/exais-football-ai/issues/19)

## Outcome and user value

Keep a wider analysis view and a tighter watching view without duplicating the original video.

## Scope

- Separate immutable source assets from named selected intervals where the initial one-clip model requires it.
- Allow several derived clip views with their own notes/tags while recording shared source ownership.

## Non-goals

- Automatic full-game segmentation or joining unrelated source files.

## Acceptance checks

- [ ] Two named selections reference one physical source hash and independent start/end values.
- [ ] Editing one view does not modify another view's trim or human labels.
- [ ] Notes and exports identify both their source asset and selected view.
- [ ] Existing first-release clips migrate without changed IDs or lost history.
- [ ] The owner can select a wider context view for calibration while retaining the tight review view.

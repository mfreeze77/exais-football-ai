# EFA-036 — Link tracks to roster players through explicit scoped review

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** identity
**GitHub issue:** [#36](https://github.com/mfreeze77/exais-football-ai/issues/36)

## Outcome and user value

Find a known player's appearances while keeping identity decisions separate from geometry-based role predictions.

## Scope

- Add manual mapping from run/clip/track/time interval to a roster record with evidence notes.
- Support unknown identity, correction, revocation, and history without automatic cross-game propagation.

## Non-goals

- Face recognition, automatic persistent biometric identity, or treating a jersey number as globally unique.

## Acceptance checks

- [ ] A reviewed mapping includes clip ID, run ID, track ID, interval, roster ID, and decision provenance.
- [ ] Repeated track IDs in another clip/run have no identity effect.
- [ ] Revoking or changing a mapping updates derived player views without rewriting historical decisions.
- [ ] Ambiguous/occluded tracks can remain unassigned.
- [ ] Player-filter results distinguish manual clip tags from specifically reviewed track identity.

## Risks and evidence boundaries

- A stitched track may accidentally include two people; interval-scoped review must allow correction.
- Jerseys and positions can change between games.

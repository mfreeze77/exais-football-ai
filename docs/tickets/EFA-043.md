# EFA-043 — Export portable metadata and selected film packages

**Status:** planned
**Milestone:** M4 — Desktop convenience, recovery, scale, and release confidence
**Priority:** P1
**Area:** interchange
**GitHub issue:** [#43](https://github.com/mfreeze77/exais-football-ai/issues/43)

## Outcome and user value

Carry organized review work into another application or share a selected set as files.

## Scope

- Export stable JSON/CSV metadata and a selected clip/playlist package with provenance manifests.
- Include optional trimmed MP4s, notes, and preserved sidecars under deterministic safe filenames.

## Non-goals

- Sending files to other people automatically, public links, or presenting editable KVA metadata as burned-in video text.

## Acceptance checks

- [ ] A package identifies source clip/hash, selected interval, label revision, playlist order, and included files.
- [ ] Metadata preserves Unicode, multiple tags/players, and null/optional values without ambiguity.
- [ ] CSV output escapes delimiters/newlines and handles spreadsheet-formula injection safely.
- [ ] The owner can export metadata without copying original or derived videos.
- [ ] Package inspection/import validates checksums/schema and does not run executable content.
- [ ] A selected package contains only the requested clips and associated records.

# EFA-040 — Package a convenient macOS local launcher

**Status:** planned
**Milestone:** M4 — Desktop convenience, recovery, scale, and release confidence
**Priority:** P1
**Area:** desktop
**GitHub issue:** [#40](https://github.com/mfreeze77/exais-football-ai/issues/40)

## Outcome and user value

Open the film library on the owner's Mac without reconstructing a development environment for every session.

## Scope

- Provide a documented local launcher/bundle that opens the same-origin UI and uses a stable user-data location.
- Qualify Intel/Apple Silicon targets actually available, external FFmpeg setup, process ownership, and clean shutdown.

## Non-goals

- Claiming Kinovea runs on Apple Silicon, bundling heavy CV models, or claiming notarization/signing that was not performed.

## Acceptance checks

- [ ] A clean supported Mac can install/start the documented package and reopen the same persisted library.
- [ ] Launching twice focuses/reuses or cleanly rejects the second instance instead of starting competing workers.
- [ ] Paths with spaces and Unicode work for uploads, data, and export downloads.
- [ ] Missing FFmpeg and unavailable Kinovea are visible with useful setup guidance.
- [ ] The release matrix records hardware, OS, signing status, and executed checks separately for each tested architecture.

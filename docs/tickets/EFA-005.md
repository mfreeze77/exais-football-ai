# EFA-005 — Review source video with a non-destructive selected interval

**Status:** implemented
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** playback
**GitHub issue:** [#5](https://github.com/mfreeze77/exais-football-ai/issues/5)

## Outcome and user value

Tighten each clip for future watching while keeping the complete source available.

## Scope

- Support byte-range/HEAD source playback, selected in/out times, looping, and browser playback-speed controls.
- Save 0 <= start_seconds < end_seconds <= source_duration as metadata.

## Non-goals

- Guaranteed frame-accurate browser seeking, drawing tools, or deleting the original media outside the selected interval.

## Acceptance checks

- [x] Valid byte-range requests return the expected bytes and invalid ranges return a controlled response.
- [x] A trim update never changes the source file hash or source_duration.
- [x] Invalid, reversed, non-finite, or out-of-bounds selections are rejected.
- [x] The UI can mark in/out, play or loop the saved interval, and reopen it after a restart.
- [x] All displayed/editable timestamps refer to the original source rather than a previously exported trim.

## Risks and evidence boundaries

- Browser decoders may seek to nearby frames; exact frame navigation is a later qualification task.
- Very tight trims can remove pre-snap alignment needed by later CV analysis.

# EFA-032 — Execute bounded, resumable external analysis jobs

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** jobs
**GitHub issue:** [#32](https://github.com/mfreeze77/exais-football-ai/issues/32)

## Outcome and user value

Run an optional analysis without freezing review or losing the record of what was processed.

## Scope

- Supervise the configured external Python process using persistent per-run directories and stable play IDs.
- Snapshot inputs, log bounded stage progress, support cancel/retry, and retain terminal failure reasons.

## Non-goals

- Shell-command input, arbitrary filesystem/executable selection, or silently resuming with changed source/calibration/model inputs.

## Acceptance checks

- [ ] A run snapshot records source hash, trim/context, calibration revision, provider commit, detector/weights, and command version.
- [ ] Process invocation uses argument arrays, managed paths, time/resource limits, and explicit local-only inputs.
- [ ] Cancellation terminates owned processes and never advertises partial results as successful.
- [ ] A retry creates a new attempt while preserving previous errors and artifacts.
- [ ] Restart recovery distinguishes interrupted, retryable, failed, and complete work.
- [ ] A deterministic fake runner qualifies supervision independently from later real-model accuracy tests.

# EFA-020 — Add accurate frame navigation and timeline previews

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** playback
**GitHub issue:** [#20](https://github.com/mfreeze77/exais-football-ai/issues/20)

## Outcome and user value

Move precisely around the snap, first step, and contact instead of repeatedly guessing timestamps.

## Scope

- Generate a bounded frame/timestamp index and thumbnail strip tied to source media.
- Support next/previous decoded-frame navigation and snapping in/out points to known timestamps.

## Non-goals

- Claiming constant frame rate for every file or using browser currentTime alone as proof of frame accuracy.

## Acceptance checks

- [ ] A synthetic frame-numbered fixture confirms forward/back navigation targets the intended frame.
- [ ] Variable-frame-rate input uses recorded presentation timestamps rather than frame/fps arithmetic.
- [ ] Timeline thumbnails map to source-relative times and regenerate when their source hash differs.
- [ ] Preview caches have documented disk bounds and never replace originals.
- [ ] The UI explains any fallback to approximate browser seeking.

## Risks and evidence boundaries

- Variable rates, rotation, and nonzero stream origins can misalign overlays.
- Indexing cost should not block ordinary playback.

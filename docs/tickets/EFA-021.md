# EFA-021 — Qualify keyboard, accessibility, and small-screen review

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** ui
**GitHub issue:** [#21](https://github.com/mfreeze77/exais-football-ai/issues/21)

## Outcome and user value

Use the film room comfortably for repeated review sessions with a keyboard or a smaller display.

## Scope

- Provide documented shortcuts, semantic form labels, focus management, and accessible status messages.
- Refine responsive review/catalog layouts and large target sizes without obscuring video controls.

## Non-goals

- A mobile-native app, remote synchronization, or changing clip metadata through ambiguous single-key shortcuts.

## Acceptance checks

- [ ] Keyboard-only navigation can import/select a clip, edit metadata, add a note, and export.
- [ ] Shortcuts are inactive inside text-editing controls and dialogs return focus to their opener.
- [ ] Errors, saving states, and job completion are announced without stealing focus.
- [ ] Review tools remain usable at defined desktop and small-browser widths.
- [ ] Contrast, labels, and focus checks are recorded against actual rendered pages.

## Risks and evidence boundaries

- Automated accessibility scans do not establish usability for a full review session.
- Playback shortcuts can conflict with browser defaults and text entry.

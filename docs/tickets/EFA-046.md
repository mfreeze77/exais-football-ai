# EFA-046 — Qualify larger libraries and a representative media matrix

**Status:** planned
**Milestone:** M4 — Desktop convenience, recovery, scale, and release confidence
**Priority:** P1
**Area:** quality
**GitHub issue:** [#46](https://github.com/mfreeze77/exais-football-ai/issues/46)

## Outcome and user value

Keep film retrieval and playback useful after a season of clips and varied camera formats.

## Scope

- Benchmark a synthetic catalog with 10,000 clips and realistic many-to-many labels/playlists.
- Test declared codecs, resolutions, frame rates, orientation metadata, silent/audio sources, and slow/damaged files.

## Non-goals

- Universal codec guarantees, invented hardware performance, or repeated optional tests after a stated gate is satisfied.

## Acceptance checks

- [ ] On the recorded reference machine, paginated common filters over 10,000 metadata records meet a documented 500 ms p95 target or remain unqualified.
- [ ] Browser browsing remains bounded rather than loading every full clip/media resource at once.
- [ ] The supported media matrix records import, preview, range playback, exact export, and audio outcomes separately.
- [ ] Unsupported formats receive actionable messages instead of a successful-looking broken thumbnail.
- [ ] Large imports/exports do not starve metadata editing and job state remains truthful.
- [ ] Benchmarks include schema/index/query details sufficient to reproduce observed limits.

# EFA-004 — Save metadata with optimistic concurrency and revision restore

**Status:** in_progress
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** catalog
**GitHub issue:** [#4](https://github.com/mfreeze77/exais-football-ai/issues/4)

## Outcome and user value

Edit labels confidently and recover earlier review choices without silently losing another tab's changes.

## Scope

- Update title, description, phase, review status, game, tags, player references, and selected range with a required version.
- Persist revision snapshots and restore editable metadata as a new revision.

## Non-goals

- Full undo of source files, automatic conflict merging, or removal of prior history.

## Acceptance checks

- [ ] A current-version PATCH increments version and records the previous/new review state consistently.
- [ ] A stale-version PATCH returns 409 and leaves the stored clip unchanged.
- [ ] Replacing tag/player lists validates and normalizes their inputs without partially applying invalid relationships.
- [ ] Restoring a prior revision requires current_version and creates a new version rather than rewinding history.
- [ ] Immutable source fields and invalid enum values are rejected.

## Dependencies

## Risks and evidence boundaries

- Whole-list replacement is deliberate; UI must preserve unsaved edits until success or an explicit conflict resolution.
- A restored timestamp must still satisfy the immutable source duration.

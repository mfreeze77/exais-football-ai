# EFA-023 — Create source-anchored drawings and keyframe snapshots

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** review
**GitHub issue:** [#23](https://github.com/mfreeze77/exais-football-ai/issues/23)

## Outcome and user value

Mark the foot placement, pursuit line, or player position that a future viewing should focus on.

## Scope

- Add original-code arrows, circles, text, and simple freehand annotation with visibility intervals.
- Store normalized geometry, source dimensions/time, and versioned snapshot exports.

## Non-goals

- Copying Kinovea GPL drawing implementations, physical measurement claims, or automatic biomechanical coaching.

## Acceptance checks

- [ ] A drawing remains aligned when the player viewport is resized without changing the video coordinate system.
- [ ] Visibility intervals and keyframes use original-source timestamps.
- [ ] Undo/redo affects annotation revisions and never deletes source film.
- [ ] Exported stills visibly include chosen annotations and retain source/time attribution in their manifest.
- [ ] HTML/script-like annotation text is safely rendered and exported.

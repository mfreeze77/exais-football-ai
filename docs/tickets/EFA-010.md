# EFA-010 — Create ordered playlists and watch a focused set of clips

**Status:** implemented
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** playlists
**GitHub issue:** [#10](https://github.com/mfreeze77/exais-football-ai/issues/10)

## Outcome and user value

Return to a useful sequence of plays without copying video files into more folders.

## Scope

- Create playlists with title/description and replace ordered clip membership.
- Display each playlist and play its clips in the saved order.

## Non-goals

- Smart playlists, exported compilation movies, progress tracking, or per-viewer accounts.

## Acceptance checks

- [x] Saving an ordered clip list and reopening it preserves order.
- [x] Unknown clip IDs and duplicate membership are rejected atomically.
- [x] Reordering does not duplicate or modify original media.
- [x] A playlist containing an archived clip has an explicit visible state rather than silently changing order.
- [x] The UI can create a playlist and watch more than one clip from it.

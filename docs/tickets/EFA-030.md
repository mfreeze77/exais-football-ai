# EFA-030 — Create manual field calibration with validated geometry

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P1
**Area:** analysis
**GitHub issue:** [#30](https://github.com/mfreeze77/exais-football-ai/issues/30)

## Outcome and user value

Give the analyzer enough field context to place tracked participants in meaningful coordinates.

## Scope

- Add a source-frame picker and editable pixel-to-field calibration points with units/field profile.
- Store calibration revision, source hash, frame/timestamp, image dimensions, and provenance.

## Non-goals

- Unreviewed automatic calibration or physical-accuracy claims from too few, collinear, or poorly distributed points.

## Acceptance checks

- [ ] At least four valid, spatially distributed correspondences are required before a calibration is runnable.
- [ ] Non-finite, duplicate, out-of-image, and geometrically degenerate input receives a useful error.
- [ ] Saving then reopening calibration preserves its source frame and coordinate/units convention.
- [ ] The owner sees a projected grid/reprojection preview and can correct points before analysis.
- [ ] Changing source geometry, crop, or orientation invalidates an incompatible calibration until reviewed.

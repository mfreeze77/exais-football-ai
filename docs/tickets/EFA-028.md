# EFA-028 — Launch a Kinovea comparison from saved clip pairs

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** integrations
**GitHub issue:** [#28](https://github.com/mfreeze77/exais-football-ai/issues/28)

## Outcome and user value

Open a selected pair for detailed external comparison with the correct film context.

## Scope

- Extend the configured Windows launcher for documented second-video arguments and compatible per-clip sidecars.
- Connect a saved comparison to the external handoff while preserving explicit unsupported states.

## Non-goals

- A Kinovea replacement, DLL embedding, or assuming every installed version supports the same arguments.

## Acceptance checks

- [ ] Command construction passes both managed video paths as separate arguments and cannot accept request-supplied switches.
- [ ] Capability checks distinguish single-video support from a version-qualified comparison launch.
- [ ] The comparison record identifies both source hashes and chosen offsets even if Kinovea cannot import every setting.
- [ ] Missing or moved executable/sidecars produce useful recovery instructions.
- [ ] Real Windows launch acceptance is recorded under the Windows qualification ticket before claiming end-to-end support.

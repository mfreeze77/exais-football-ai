# EFA-007 — Find film by search and combined football filters

**Status:** implemented
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** catalog
**GitHub issue:** [#7](https://github.com/mfreeze77/exais-football-ai/issues/7)

## Outcome and user value

Retrieve useful clips by what they show instead of browsing an expanding folder tree.

## Scope

- Implement query, game, player, tag, phase, review-status, favorite, and archive filters.
- Return totals and bounded pagination; show tag counts and library summary statistics.

## Non-goals

- Semantic search, natural-language query agents, or automatic play classification.

## Acceptance checks

- [x] Combining filters returns only records satisfying the documented intersection.
- [x] Default clip searches exclude archived clips while the explicit archived view can retrieve them.
- [x] Pagination returns stable pages with a total matching the same filters.
- [x] Empty searches and no-match searches display clear UI states.
- [x] Invalid identifiers/filter values return documented errors rather than leaking SQL details.

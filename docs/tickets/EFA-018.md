# EFA-018 — Apply batch metadata edits with preview and recovery

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** catalog
**GitHub issue:** [#18](https://github.com/mfreeze77/exais-football-ai/issues/18)

## Outcome and user value

Label many clips from one game quickly without accidentally replacing unrelated review work.

## Scope

- Add multi-select and batch game/player/tag/review actions with a concrete change preview.
- Use per-clip versions, an auditable batch ID, and a recoverable before-state.

## Non-goals

- Bulk source deletion or silently resolving concurrent edits.

## Acceptance checks

- [ ] Preview identifies affected clips and distinguishes add/remove/replace tag semantics.
- [ ] A stale clip revision prevents that clip from being overwritten and produces an explicit conflict result.
- [ ] The chosen all-or-nothing or partial-success policy is documented and tested.
- [ ] Undo restores only fields changed by the batch and checks for subsequent edits.
- [ ] A batch cannot assign nonexistent games/players or archive a clip outside the selected set.

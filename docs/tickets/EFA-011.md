# EFA-011 — Run durable audio-preserving trim exports

**Status:** in_progress
**Milestone:** M1 — Working local film library and safe external adapter foundations
**Priority:** P0
**Area:** media
**GitHub issue:** [#11](https://github.com/mfreeze77/exais-football-ai/issues/11)

## Outcome and user value

Produce a tightened MP4 that remains tied to the exact review settings used to create it.

## Scope

- Queue exports from a frozen clip revision and retain job state/errors in SQLite.
- Use bounded FFmpeg processing, optional source audio mapping, verified H.264 output, and atomic publication.

## Non-goals

- Real-time transcoding, AI overlay rendering, task cancellation, or a distributed job queue.

## Acceptance checks

- [ ] A real generated fixture exports the selected duration within a declared codec tolerance and retains its audio stream.
- [ ] A metadata edit made after enqueue does not change the queued export's interval or clip_version.
- [ ] Source bytes remain unchanged and the completed job provides a valid download.
- [ ] A nonzero process exit, missing executable, timeout, or write failure becomes a meaningful failed job.
- [ ] Restart marks interrupted queued/running work failed according to the contract instead of announcing completion.
- [ ] A partial output is never exposed as a completed artifact.

# EFA-026 — Inspect supported KVA versions and propose metadata imports

**Status:** planned
**Milestone:** M2 — Faster film study and deeper Kinovea interoperability
**Priority:** P1
**Area:** integrations
**GitHub issue:** [#26](https://github.com/mfreeze77/exais-football-ai/issues/26)

## Outcome and user value

Bring known Kinovea working-zone and keyframe information into the catalog with an explicit review step.

## Scope

- Build release-specific KVA fixtures and a read-only normalized summary for recognized working-zone, keyframe, comment, and time-origin fields.
- Present proposed catalog changes alongside the original preserved XML and unsupported elements.

## Non-goals

- Arbitrary KVA schema compatibility, conversion of every drawing, or automatic writes back to Kinovea.

## Acceptance checks

- [ ] Fixtures from each declared supported release parse to expected source times and comments.
- [ ] Unknown fields are retained in the original sidecar and reported as unsupported rather than discarded.
- [ ] An import proposal identifies its sidecar hash, clip source hash, and KVA release/schema.
- [ ] The owner must accept a preview before catalog trim or notes change.
- [ ] Incorrect video associations or time-origin ambiguity block proposed timestamp updates.

# EFA-038 — Transfer calibration between compatible plays with review

**Status:** planned
**Milestone:** M3 — Qualified optional football computer vision
**Priority:** P2
**Area:** analysis
**GitHub issue:** [#38](https://github.com/mfreeze77/exais-football-ai/issues/38)

## Outcome and user value

Reduce repeated field-point marking when clips share a usable camera setup.

## Scope

- Attempt upstream-compatible calibration transfer from an explicitly selected same-game reference.
- Record reference/target hashes, transform quality, candidate points, and a manual accept/edit/reject decision.

## Non-goals

- Blind reuse across games/camera angles or overwriting an existing manual calibration.

## Acceptance checks

- [ ] A accepted transfer records its reference calibration revision and target source hash.
- [ ] A target with incompatible geometry or inadequate matching is marked failed/needs_review.
- [ ] Existing manual calibration is never replaced without an explicit reviewed change.
- [ ] A visual grid/reprojection preview exposes a bad transfer before position processing.
- [ ] Qualified and deliberately mismatched test pairs demonstrate the rejection path.
